# The Dang Greenery — Premium Website

## Run locally
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open `index.html` with Live Server (or open it directly in a browser).

## Homepage slideshow
- Uses the seven supplied venue photos in `images/`.
- Automatically changes every 3 seconds.
- Includes photo indicators and a pause/play control.
- No download button is displayed. Note: a public website cannot fully prevent screenshots or saving images from a browser.

## Included
- Responsive premium green-themed homepage and content sections
- English/Gujarati language switch
- Dark/light theme toggle
- Seven-photo hero slideshow
- Gallery lightbox
- WhatsApp, phone, email and Google Maps links
- Stay/room booking clearly marked Coming Soon
- Privacy and Terms draft pages
- Automatic current year in footer

## Important before publishing
- This is the front-end website package. Supabase authentication, database-backed admin panel, managed menu/product/offer/gallery content and private feedback/complaint storage are **not connected in this package**.
- Menu prices, product prices, stock, live offers, reviews, and room tariffs are not invented or displayed as facts. Confirm these with the owner before adding them.
- Verify the Google Maps pin, address spelling, business contact details, photo approvals and legal pages before launch.
- The language toggle translates elements explicitly marked for English/Gujarati; owner review of Gujarati wording is recommended.
- No paid services or billing are activated by this package.
